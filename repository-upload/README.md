# IngeTrazo Extensions

Three Python extensions for IngeTrazo 0.5.7, licensed GPL-3.0-or-later.

| Extension | Version | Documentation |
|---|---|---|
| Kitchen Maker | 1.0.2 | [ingetrazo_kitchen_maker](ingetrazo_kitchen_maker/README.md) |
| Stair Maker with Railings | 1.1.0 | [make_stair](make_stair/README.md) |
| Bevel | 1.0.2 | [ingetrazo_bevel](ingetrazo_bevel/README.md) |

## Install

Download the desired `.py` file. In IngeTrazo, choose **Extensions → Open plugins folder**, close the app, copy the file into that folder, and restart. Keep the original filename; remove older duplicate copies. Only the Python file is needed at runtime. Screenshots, examples, and documentation are optional.

Read each extension README for features, limits, dependencies and provenance. These extensions use the host IngeTrazo runtime, PySide6 and (Kitchen Maker and Bevel) NumPy.
