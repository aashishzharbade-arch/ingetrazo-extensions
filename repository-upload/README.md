## Install

Download the desired `.py` file. In IngeTrazo, choose **Extensions → Open plugins folder**, close the app, copy the file into that folder, and restart.

Keep the original filename and remove older duplicate copies. Only the Python file is needed at runtime. Screenshots, examples, and documentation are optional.

Read each extension README for features, limits, dependencies, and provenance. These extensions use the host IngeTrazo runtime and PySide6; Kitchen Maker, Bevel, and Curve Tools may also use NumPy.
